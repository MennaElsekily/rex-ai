
# REX AI - Project Requirements

## Project Objective
Build an AI system that automates academy operations
using five specialized AI agents.

## Agent 1: Course Assistant
Recommends suitable courses using student information
and approved academy course data.

## Agent 2: Tender Research
Finds relevant educational tenders in Egypt and
Saudi Arabia and summarizes the opportunities.

## Agent 3: Curriculum Agent
Creates structured course curricula and identifies
gaps against relevant educational standards.

## Agent 4: Document Generation
Generates educational documents using templates
and exports them as downloadable PDFs.

## Agent 5: Marketing Agent
Creates promotional content based on approved
course information.

## Sprint 1 Objectives
- Set up project documentation.
- Assign team responsibilities.
- Collect initial course data.
- Design the system architecture.
- Prepare the course knowledge base.
- Build a basic course recommendation chatbot.

## Final Goal
Deliver a working multi-agent system in which
at least two agents interact in one workflow.
